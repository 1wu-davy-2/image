中转站怎么调用

用户每天签到领取额度，生图时扣额度。GPT、Nano Banana、Gemini 官方直连的 Key 和剩余余额在 管理端 维护。服务端用还有余额的 Key 去请求中转站。

GPT 生图：POST /v1/images/generations，编辑是 /v1/images/edits。先走异步再轮询 /v1/images/tasks/{task_id}，异步不存在时改同步。字段有 model、prompt、size、quality。示例模型 gpt-image-2.5-flare、gpt-image-1。

Nano Banana：同一套生图接口，模型用 gemini-2.5-flash-image（香蕉）、gemini-3-pro-image、gemini-3.1-flash-image。生图接口不收这个模型时，改走 POST /v1/chat/completions，和 UU 控制台对 Gemini 分组的做法一致。

GEMINI官方直连-带生图：POST /v1beta/models/{模型}:generateContent。正文是 Gemini 官方格式，generationConfig.responseModalities 含 IMAGE，画幅和分辨率放在 imageConfig。参考图以 inlineData 放进 contents。

Gemini 批量生图：POST /v1/images/batches，正文是 model、provider、items。之后用 GET /v1/images/batches/{id} 查状态、/items 看条目、/download 取 ZIP，还能 /cancel 取消。这一族要单独配一把「Gemini 批量生图」类型的 Key。

蒙版：图生图时可以用 mask 指定只重绘哪一块。GPT 走 multipart 的 mask 文件字段、或 JSON 的 mask.image_url；Gemini 官方直连没有这个能力。
